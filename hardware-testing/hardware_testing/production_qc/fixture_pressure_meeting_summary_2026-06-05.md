会议日期：2026-06-05  
主题：最新气压泄漏测试数据复盘、工装风险汇总、下一步验证方案确认

## 1. 会议目标

本次会议主要解决三个问题：

1. 汇总最新脚本下 P200H、P1000H、P200H 老化移液器的气压泄漏测试表现。
2. 判断当前低通过率主要来自移液器本体、测试方法，还是气压工装/取针管一致性。
3. 确认后续生产测试策略：阈值、工装维护、异常通道处理、取针管流程是否需要调整。

## 3. 当前测试逻辑简述

最新脚本的核心判断逻辑如下：

1. 每轮测试会记录 pre、insert、post 以及不同体积 holding/dispensed 阶段的压力数据。
2. 泄漏率以 holding 阶段的 60s leak-rate 作为主要判断依据。
3. 对每个通道按体积分别判断 1ul、50ul、200ul 的泄漏率是否超过阈值。
4. insert 阶段会检查取针管后的气压有效性，如果多轮 insert 压力不达标，会将该通道判为 fail。
5. 如果某通道 insert 阶段压力数据全部为 0，程序会自动停止测试，并提示“程序自动停止测试，原因工装可能存在线脱落”。
6. 当前 CSV/Google 模板核心字段保持兼容，重点字段包括 min、max、60s-leak-rate、average、stability、CHANNEL-LEAK-SUMMARY。

## 4. 已观察到的主要现象

### 4.1 低通过率不一定等价于移液器批量异常

已读取到的 P200H 样例中，整体 fail 不是因为 1ul 泄漏率超标，而是 insert 压力不足叠加 50ul/200ul fail。该报告中 CH60 的 insert min 为 381.95，低于 500 规格，因此这类失败应优先归为“过程/工装/取针管状态异常”，不能直接归因为移液器泄漏。

如果多台 P200H 在相同工装上表现为大面积 fail，需要优先排查系统性因素，而不是直接判断移液器本体全部异常。重点看：

1. 是否总是固定通道或固定列异常。
2. 是否固定体积段更容易异常，例如 1ul 更敏感，200ul 更容易暴露大泄漏。
3. 是否 insert 压力不稳定，说明取针管/密封状态本身不一致。
4. 老化移液器是否与新移液器出现相同通道模式，如果相同，工装因素更大。

### 4.2 工装通道偏差是当前最需要关注的问题

前期数据中已经出现过固定通道长期偏高的现象，尤其需要关注：

| 通道 | 风险表现 |
| --- | --- |
| CH9 | 多组数据中出现系统性偏高，疑似工装通道本底偏差或密封一致性问题 |
| CH12 | 多组数据中泄漏率容易偏高，部分数据出现极端值 |
| CH86 | 前期分析中属于风险通道，建议继续跟踪 |

会议建议不要只看单份报告 fail，而是统计每个 channel 在所有报告中的 fail 频次。如果某通道在不同移液器、不同测试轮次中反复 fail，优先判定为工装通道风险。

### 4.3 取针管一致性会显著影响结果

目前已经对比过两种测试方式：

1. 只取一次针管，连续测试多个体积/多轮。
2. 1ul、50ul、200ul 分开取针管后分别测试。

分开取针管的优点是每个体积段都从新的取针管状态开始，能减少前一个体积测试对后续体积的影响；缺点是测试时间更长，也会引入更多次取针管动作的不确定性。会议需要结合数据确认哪种方式整体 CV 更低、fail 更少、通道分布更稳定。

### 4.4 insert 阶段压力是重要的过程质量指标

insert 压力不是最终泄漏率，但它能反映取针管压入、密封、工装接触是否正常。如果 insert 压力偏低或为 0，后面的 holding leak-rate 即使异常，也不能直接归因于移液器泄漏。

建议会议中将异常拆成两类：

1. 过程异常：insert <= 500、insert 全 0、传感器无数据、取针管失败。
2. 泄漏异常：insert 正常，但 holding leak-rate 超阈值。

只有第二类才更接近移液器本体泄漏异常。

## 5. 工装问题清单

| 问题 | 现象 | 风险 | 建议 |
| --- | --- | --- | --- |
| 固定通道泄漏率偏高 | 多台移液器同一 channel fail | 误杀正常移液器 | 统计 channel fail 频次，必要时维修/更换工装通道 |
| insert 压力偏低 | 取针管后压力不足 | 后续泄漏率失真 | 保留 insert fail-count，并作为过程异常单独输出 |
| insert 全 0 | 某通道无压力数据 | 疑似线脱落或传感器/连接异常 | 程序已改为自动停止，避免继续误测 |
| 取针管一致性不足 | 同一移液器多轮差异大 | CV 偏高，误判 fail | 对比“一次取针管”和“分开取针管”的 CV/通过率 |
| 传感器数据延迟 | 电子上报存在延迟 | 过早采样导致数据不准 | 保留 delaytime=3，不建议盲目缩短 |
| 工装位置/撞机风险 | 脚本位置或 fixture slot 变化 | 设备损坏 | 位置变更必须先 dry run/低速验证 |

## 6. 建议的会议结论方向

建议会议先形成以下共识：

1. 当前低通过率需要先拆分为“工装/过程异常”和“真实泄漏异常”，不能直接把所有 fail 归因于移液器。
2. 对固定高风险通道，需要按所有报告统计 fail 频次，超过一定比例后应作为工装维护项处理。
3. insert 压力检查必须保留，因为它能提前识别取针管失败、接触异常和线脱落。
4. delaytime=3 由电子工程师确认，不建议为了提速直接删除。
5. 是否采用“分开取针管测试”需要用通过率、CV、重复性共同判断，而不是只看单次结果。

## 8. 建议会议决策项

本次会议建议明确以下决策：

1. 是否继续使用当前 hard threshold，还是按 channel/volume 建立分位数阈值。
2. 是否对 CH9、CH12、CH86 等高风险通道做工装维修或临时风险规避。
3. 是否在生产测试中区分“过程 fail”和“泄漏 fail”，避免误判移液器。
4. 是否采用分开取针管方案作为正式流程。
5. 是否需要增加工装日常点检流程，例如每日空跑、insert 压力检查、全 0 通道检查。
