## Opentrons App Changes in 26.6.0

Welcome to the v26.6.0 release of the Opentrons OT-2 App! This release is designed specifically for use with Opentrons OT-2 and includes other new features, improvements, and bug fixes.

**Flex robots will not appear in the Opentrons OT-2 App.** To control Flex robots, download the Opentrons App from <https://opentrons.com/app>. You can run both apps if you have both types of robots in your lab.

### New Features

- Protocol visualization for OT-2
  - Bring your protocols to life in the Opentrons OT-2 App!
  - View Python protocol steps like tip pickup and disposal, labware and liquid moves, module steps, and more alongside a view of the robot deck.
  - Check new Python protocol steps and errors in a visual, playable format.
  - Assess the results of an OpentronsAI protocol before running on the OT-2.
