## Opentrons OT-2 Robot Software Changes in 26.6.0

Welcome to the v26.6.0 release of the Opentrons OT-2 robot software!

This release incorporates changes up through Python Protocol API level 2.28. This will be the highest API level supported by the OT-2. For details, see the [Versioning page](https://docs.opentrons.com/python-api/versioning/) of the Python Protocol API documentation.
