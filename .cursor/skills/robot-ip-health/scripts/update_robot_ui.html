If copy fails (some browsers block clipboard on file://), select the command in the box above and copy manually.

Why not “Run” in the browser? USB updates use serial HTTP at a fixed baud rate; Wi‑Fi calls hit the robot without CORS headers, so a plain web page cannot safely drive the update. This page only prepares the shell command — run it in Terminal from the scripts directory (or adjust the script path above).
