Welcome to the instruction manual for the Opentrons OT-2 liquid handling robot. This manual will help you set up and and get started the OT-2.

## Description

The OT-2 helps automate routine liquid-handling processes in your lab. It is a modular system that includes user-swappable pipettes, on-deck modules, and labware. You control the OT-2 through the [Opentrons App](https://opentrons.com/ot-app), our open-source [Python API](https://docs.opentrons.com/v2/), and through protocols created in the Opentrons Protocol Designer.

See [OT-2 Pipettes section](./pipettes-ot2.md) and the [OT-2 Modules section](./modules/index.md) for technical specifications and instructions on how to attach these components to your robot.

- **Use labware**: The [Labware section](./labware/index.md) works with labware, both in software and on the robot deck itself.
