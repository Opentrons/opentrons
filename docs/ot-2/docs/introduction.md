Welcome to the instruction manual for the Opentrons OT-2 liquid handling robot. This manual will help you set up and work with the OT-2.

## Description

The OT-2 automates routine liquid-handling work in your lab. It is a modular system that includes user-swappable pipettes, on-deck modules, and labware. You control the OT-2 through the [Opentrons OT-2 App](https://opentrons.com/ot-app), our open-source [Python API](../python-api/index.md), and through protocols created in the [Opentrons Protocol Designer](../protocol-designer/index.md).

## Structure of this manual

This manual is organized to help you get started quickly and operate your OT-2 efficiently. Feel free to jump into the chapters that interest you most, or review the manual from beginning to end. Here is a summary of what you will find inside:

- **Getting started**: If you are new to liquid handling robots, or simply unsure where to begin, start with [System Description](./system-description/index.md) and [Installation and Relocation](./installation/index.md). These sections cover the OT-2's components, technical specifications, and how to set up and operate the robot for the first time.

- **Control the robot**: The [Opentrons OT-2 App section](./opentrons-app/index.md) describes how to download and use this software to operate and manage your OT-2.

- **Work with instruments and modules**: Attaching pipettes and modules to the OT-2 gives it the flexibility to handle a range of liquid handling tasks. See the [OT-2 Pipettes section](./pipettes.md) and the [OT-2 Modules section](./modules/index.md) for technical specifications and instructions on how to attach these components to your robot.

- **Use labware**: The [Labware section](./labware/index.md) describes compatible labware and how to use it in the Opentrons OT-2 App and on the deck.

- **Keep OT-2 running**: Following the user-level procedures in the [Maintenance section](./maintenance/index.md) helps ensure that your robot has a long and trouble-free life.

- **And more!** For other topics, see the Appendices. Here you can find more information about Opentrons and writing code to control your OT-2.
