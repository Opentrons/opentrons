This chapter covers how the OT-2 works with labware, both in software and on the robot deck itself.

- [Labware Concepts](./concepts.md) examines the relationship between labware you place on the deck and their related software definitions. Reviewing this section can help you understand how the OT-2 recognizes the physical properties of the labware used in your protocols.

- [Labware Types](./types.md) describes specific categories of labware supported by the OT-2, including reservoirs, well plates, and tube racks.

- [Labware Definitions](./definitions.md) explains how the OT-2 uses JSON files to define and work with labware. This section covers labware that's ready to use by default, the Custom Labware Creator, and information about the technical properties (JSON schema) required to create custom definitions for unsupported labware.

You can [purchase labware from Opentrons](https://opentrons.com/products/categories/tips-&-labware) or the original equipment manufacturers. And, Opentrons is always working to add new labware definitions. See the [Labware Library](https://labware.opentrons.com/#/) for the latest listings.
