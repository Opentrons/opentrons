title: "Opentrons OT-2: Labware"
---

This chapter covers how the OT-2 works with labware, both in software and on the robot deck itself.

- [Labware Concepts](./labware.md) describes how Opentrons software encodes and uses information about physical labware items used by your OT-2. If you're new to working with a liquid handling robot, and lab automation, this is a great place to start learning about how the OT-2 knows how to work with the standard and custom labware used in your protocols.

- [Labware Types](./types.md) provides examples of different categories of labware that you'll find in the Opentrons Labware Library.

- [Labware Definitions](./definitions.md) are the files an OT-2 uses to understand the dimensions and characteristics of labware, from the labware that's in our Labware Library (and automation ready out of the box) to creating custom labware definitions with the Custom Labware Creator.

You can [purchase labware from Opentrons](https://opentrons.com/products/categories/tips-&-labware) or the original equipment manufacturers. And, Opentrons is always working to add new labware definitions. See the [Labware Library](https://labware.opentrons.com/#/) for the lasted listings.
