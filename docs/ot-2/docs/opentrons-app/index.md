---
title: "Opentrons OT-2: Opentrons App"
---

You'll work with your OT-2 through the Opentrons App. 

The app is compatible with the Opentrons OT-2 and Flex liquid handling robots. It is also the only way to interact with an OT-2 because this robot does not have an external touchscreen or another type of user interface.

The OT-2 accepts protocols created with the Opentrons [Protocol Designer](https://designer.opentrons.com/) and our [Python API](https://docs.opentrons.com/python-api/).
