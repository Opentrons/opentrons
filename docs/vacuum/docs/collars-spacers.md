## Collars

Collars establish a strong, airtight seal between your filter plate and the rest of the module to ensure proper vacuum pressure. To enable automated stacking, the collars feature custom Opentrons adapters that allow the Flex Gripper to handle them.

The module ships with two sizes to accommodate different labware:

* **Short Collar (42 mm):** Designed to hold standard ANSI/SLAS compliant filter plates.
* **Tall Collar (72 mm):** Designed to accommodate deep-well filter plates (typically up to 2 mL deep).

## Spacers

Spacers sit internally within the manifold base to control the distance between the top filter plate and the bottom collection plate. 

The module ships with two spacer sizes to accommodate varying collection plate heights:

* **Short Spacer (27 mm)**
* **Tall Spacer (34 mm)**

## Use

### Elution and Filtrate Collection
This method is used when a protocol requires collecting the filtered liquid (the eluate or specific waste) into a receiver plate inside the manifold. 

An internal spacer is required for this setup. Spacers properly position the receiver plate directly beneath the sample filter plate. Keeping this gap minimal ensures that the liquid drops cleanly into the receiver wells rather than being pulled sideways by the vacuum.

### Direct Filter to Waste
This configuration is used when the liquid being pulled through the filter plate is unwanted and should be discarded. 

In this method, no internal spacer or collection plate is needed inside the manifold. The system allows the waste to flow straight down into the manifold base and out to the off-deck carboy. The waste is safely stored in the off-deck 10L carboy, which communicates with the Flex via a liquid-level sensor to prevent overflow.
