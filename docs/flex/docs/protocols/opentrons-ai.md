OpentronsAI is a tool for creating and optimizing protocols for Opentrons robots. You can use OpentronsAI to: 

- Update existing protocols
- Create new protocols
- Get help with your protocols or the Python Protocol API. 

OpentronsAI can make mistakes. Review your protocols before running on the Flex. 

## Update an existing protocol

Upload an existing Python protocol file to OpentronsAI. You can choose from a few types of updates in the dropdown menu, like adding a Flex Stacker Module or runtime parameters to your protocol. Be sure to include details of the changes you need. 

After submitting your prompt, wait for OpentronsAI to update your protocol. Before downloading the protocol, you can ask OpentronsAI to simulate and fix any errors in the chat.
