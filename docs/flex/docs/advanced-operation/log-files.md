title: "Opentrons Flex: Flex Log Files"
---

All Flex robots keep detailed logs of their various activities, which are useful for troubleshooting. This article explains what kind of information is in the logs and how to download them from the Opentrons App.


## Understanding Flex log files

Your Flex robot constantly writes data to four different log files. These are `api.log`, `serial.log`, `server.log`, and `touchscreen.log`. As the file names suggest, each of these logs track the activities about and from different parts of the robot and its attachments. The following table summarizes the data captured in each file.

| Log file | Description |
|----|----|
| `api.log` | API logs record all movement and system activities performed by the robot. |
| `serial.log` | Serial logs record communication between a Flex and its attached instruments and modules. |
| `server.log` | Server logs record the HTTP requests (e.g., `GET`, `POST`, and `DELETE`) received and responses generated by the robot server. |
| `touchscreen.log` | Touchscreen logs record the status of the front display panel. |

For a typical Flex user, each of these log files can be difficult to interpret and understand. However, for troubleshooting purposes, it is good to know how to download these files. For troubleshooting and analysis, the data the logs contain can help Opentrons Support and internal engineering teams understand and resolve technical issues with your robot.

## Downloading log files

Follow these instructions to download the Flex log files:

1. From the Opentrons App, click **Devices** and locate the robot that you want the logs from.

2. Click the three-dot menu ( ⋮ ) and then **Robot settings**.

3. Click the **Advanced** tab to open the advanced settings page.

4. Click **Download logs**. You’ll be prompted to choose a save location when the log files are ready to download.

    !!!note
        Flex produces a single `.zip` file that contains the logs. The compressed file name includes the robot’s name followed by `_logs.zip`. For example, if your robot is called “Flex1”, the log file will be named     Flex1_logs.zip`.

5. _(Optional)_ Double-click the compressed file decompress and view the logs. The decompressed file will expand into a new folder in the same location as the downloaded file.
