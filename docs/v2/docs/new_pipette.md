# Pipettes

Opentrons pipettes are configurable devices used to move liquids throughout the working area during the execution of protocols. Flex and OT-2 each have their own pipettes, which are available for use in the Python API.

Pages in this section of the documentation cover:
- [Loading pipettes](pipettes/loading.md) into your protocol.
- [Pipette characteristics](pipettes/characteristics.md), such as how fast they can move liquid and how they move around the deck.
- [Partial tip pickup](pipettes/partial_tip_pickup.md) configurations for multi-channel pipettes. Full and partial tip pickup configurations can be combined in a single protocol.
- The [volume modes](pipettes/volume_modes.md) of Flex 50 µL pipettes, which must operate in low-volume mode to accurately dispense very small volumes of liquid.

For information about liquid handling, see [Atomic Commands](new_atomic_commands.md) and [Complex Commands](new_complex_commands.md).
