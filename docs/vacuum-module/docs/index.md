## Product description v3

The Opentrons Vacuum Module is an automated filtration system designed for Opentrons Flex. It supports protocols that use solid-phase extraction (SPE) to filter, concentrate, or purify samples.

The module consists of a single-slot manifold stack, a module caddy, a 5-liter waste jar, and a vacuum pump (flexible tubing included). The on-deck components accept ANSI/SLAS compliant vacuum filtration labware and are compatible with the Flex Gripper. You can control the Vacuum Module via the Opentrons App, the Flex touchscreen, or the Opentrons Python API.

## Product description v2

The Opentrons Vacuum Module is designed for the Flex liquid handling robot. It is used in solid-phase extraction (SPE) protocols to filter, concentrate, or purify samples. The module consists of a single-slot manifold stack, a special deck caddy, a 5-liter waste jar, along with vacuum tubes and pump. The deck module accepts ANSI/SLAS compliant vacuum filtration labware and is compatible with the Flex Gripper. To provide maximum operational flexibility, the Vacuum Module is fully controllable via the Opentrons App, Flex touchscreen, and Opentrons Python API.

## Product description v1

The Opentrons Vacuum Module is a deck-mounted sample filtration and purification system. The module consists of a single-slot manifold stack, a 5-liter waste jar, vacuum tubes and pump. It is designed for protocols that use solid-phase extraction (SPE) to filter, concentrate, or purify samples. The module is Gripper compatible and accepts ANSI/SLAS compliant labware.

The Vacuum Module is controllable via the Opentrons App, the Flex touchscreen, and the Opentrons Python API.
