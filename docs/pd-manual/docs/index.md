# **Protocol Designer Instruction Manual**

[Protocol Designer](https://designer.opentrons.com/?_gl=1*d0fqki*_ga*MjExMzExNTg5Ny4xNjYzMDk2MTg4*_ga_GNSMNLW4RY*MTY3NzUyNzk3NC45NC4xLjE2Nzc1MjkzMjUuNTguMC4w&kw=&cpn=21988025885&utm_term=&utm_source=google&utm_medium=cpc&utm_campaign=NAMER_Pmax_Brand&hsa_cam=21776817541&hsa_grp=&hsa_mt=&hsa_src=x&hsa_ad=&hsa_acc=2303351826&hsa_net=adwords&hsa_kw=&hsa_tgt=&hsa_ver=3&gad_source=1&gclid=CjwKCAiAqrG9BhAVEiwAaPu5zlI_SM6eF2U2nnAVxcryMlex_w6FmXwnc_VkhAEA5f_DsA0DGFmZUBoCW08QAvD_BwE "Protocol Designer") is a no-code, web-based tool for developing protocols that run on Opentrons robots, including the Flex and the OT-2. You can use Protocol Designer to create protocols that: 

* Mix and transfer liquids, including advanced pipetting techniques.
* Operate Opentrons modules.
* Move labware around the deck, including on and off of modules.
* Pause to verify progress or access your samples.
