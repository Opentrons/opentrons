# Compliance Ready Software Instruction Manual

Opentrons Compliance Ready software is permanently installed on your Opentrons Flex liquid handling robot to enable 21 CFR part 11-ready operation, including capturing, time-stamping, and documenting user actions, from logins to protocol runs. 

This instruction manual covers the use of Opentrons Compliance Ready software, from the irreversible changes to your Flex upon activation to daily use in the lab.
