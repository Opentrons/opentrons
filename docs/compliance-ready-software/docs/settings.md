During Opentrons Flex Compliance Ready Software activation, an Opentrons-trained representative can help you change settings to customize your day-to-day experience. For more details, see [Using Compliance Ready Software]. 

## Completing a run 

**you can specify that you must finish runs on the app (does the process of completing a protocol need to occur through the app? if yes then set the default file location)**

## File downloads

When you run protocols, your compliance ready Flex locally generates files containing robot and protocol data. These log files are yours to safely store, and are never viewed or stored by Opentrons. Read more about [files](../records.md) in this manual.

During activation, you can configure the Opentrons App to download these logs to a storage location. 

<figure class="screenshot" markdown>
![Image showing how to choose a secure, authorized storage location.](../../images/)
</figure>
<figcaption>Choose a secure, authorized storage location for your log files.</figcaption>

If robot settings, like your Flex's name, are ever changed, you may need to repeat this process.

!!! note
    There's more than one way to move files from your Flex to a storage location. You can also attach a [USB](../docs/devices.md) and move the files to a computer yourself.
