# OT-2 Attachment Steps

<div class="instruction-list" markdown>

To install the Temperature Module on your OT-2:

1. Choose the supported deck slot you want to use for the module and press it gently into place.

2. Connect the USB cable to the module and to a USB port on the OT-2.

3. Connect the power cable to the module. The Temperature Module has an asymmetrical 4-pin power connector. When connecting the power cable to the module:

    - Match the connector's flat side to the flat side of the module's power port.
    - Aligned cables attach easily; misaligned cables do not.
    - _Do not_ plug the power cable into a wall outlet until instructed to do so.

    <figure class="screenshot" markdown>
    ![Image of aligned power cable](images/module-power-connector.png){style="width: 60%; margin-left: 0;"}
    </figure>

4. Connect the power cable to a wall outlet. Gently press the on/off switch to turn the module on.

</div>

If the temperature LCD is illuminated, the module is powered on.

When successfully connected, the module appears in the Instruments and Modules section on your robot’s device detail page in the Opentrons App. The module is ready to use and does not require calibration on an OT-2.
